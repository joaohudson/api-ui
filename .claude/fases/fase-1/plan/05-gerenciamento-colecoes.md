# 05 — Gerenciamento de coleções

## Objetivo
Implementar CRUD de coleções e das requisições que pertencem a cada coleção.

## Dependências
4 (persistência local).

## Escopo
- Criação, edição, remoção e listagem de coleções.
- Criação, edição, remoção e listagem de requisições dentro de uma coleção.
- Modelo de dados de coleção (id, nome, requisições, referência a ambientes/variáveis — usado pela atividade 6).
- Modelo de dados de requisição salva (verbo, URL, parâmetros, headers, body).
- Uso da camada de persistência (atividade 4) para gravar e ler os dados.

## Fora de escopo
Variáveis de ambiente (atividade 6), exportação (atividade 7).

## Entregáveis
Módulo Rust com funções de CRUD de coleções e requisições.
