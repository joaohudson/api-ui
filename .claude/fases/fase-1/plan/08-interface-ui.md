# 08 — Interface de usuário

## Objetivo
Construir o layout geral e a navegação da aplicação em HTML, CSS e JS vanilla.

## Dependências
1 (estrutura base do projeto).

## Escopo
- Estrutura visual geral: barra lateral com lista de coleções e área principal de trabalho.
- Navegação entre coleções e requisições salvas.
- Áreas para: lista de coleções, lista de requisições de uma coleção, área de edição de requisição (preenchida pela atividade 9) e área de resposta (preenchida pela atividade 10).
- Estilização base em CSS vanilla, sem framework de UI.
- Estrutura de arquivos JS para organização do frontend, sem framework.

## Fora de escopo
Formulário de requisição (atividade 9), exibição de resposta (atividade 10), temas ou customização visual avançada.

## Entregáveis
Shell da aplicação navegável, sem funcionalidade de requisição ainda ativa.
